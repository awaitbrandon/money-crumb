# moneycrumb-site

MoneyCrumb's public pages, served by GitHub Pages.

- `privacy.html`: the privacy policy Google Play links to. Its text is the launch kit's policy
  (`docs/LAUNCH-KIT.md` in the app repo). When one changes, change the other, along with
  `PRIVACY_UPDATED` in `src/lib/privacy.ts`.
- `index.html`: a short landing page.

Publish: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
